# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability in SeeNOW, please **DO NOT** create a public issue on GitHub.

Instead, please send an email to security-report@seenow.internal or open a private GitHub Security Advisory.

Please include:
- A description of the vulnerability
- Detailed steps to reproduce
- Potential impact
- Any suggested remediations

You will receive an acknowledgment within 48 hours, followed by updates on the remediation progress.
