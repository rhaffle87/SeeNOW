## 3. Rangkuman Poin Kunci & Intisari Ujian (Key Exam Takeaways)

- **5 Karakteristik Esensial NIST:**
  1. **On-Demand Self-Service:** Pengguna dapat memesan kapasitas komputasi (CPU/RAM/storage) kapan saja secara mandiri tanpa kontak fisik/manual dengan penyedia.
  2. **Broad Network Access:** Kemampuan diakses melalui jaringan standar via PC, laptop, tablet, atau smartphone.
  3. **Resource Pooling:** Sumber daya komputasi penyedia disatukan dalam multi-tenant pool untuk melayani banyak konsumen secara dinamis.
  4. **Rapid Elasticity:** Skalabilitas instan naik atau turun sesuai beban kerja (*scale up / scale out*).
  5. **Measured Service:** Monitoring pemakaian transparan dengan model pembayaran berbasis pemakaian riil (*pay-as-you-go*).
