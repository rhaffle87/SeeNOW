## 3. Rangkuman Poin Kunci & Intisari Ujian (Key Exam Takeaways)

- **Tren Utama Cloud Computing Masa Depan:**
  - **Cloud-Native & Container (Docker / Kubernetes):** Pengemasan aplikasi ringan yang berbagi kernel host, startup milidetik, densitas komputasi sangat tinggi.
  - **Serverless (FaaS):** Pengembang hanya mengunggah fungsi kode; alokasi dan terminasi server dikelola otomatis oleh cloud.
  - **Edge Computing:** Membawa daya komputasi ke dekat sumber data (base station 5G, gateway pabrik, perangkat IoT) untuk memangkas latensi transfer.
  - **AI + Cloud:** Pusat data cloud menyediakan daya komputasi GPU/NPU masif untuk pelatihan dan inferensi kecerdasan buatan terdistribusi.
