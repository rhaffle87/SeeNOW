## 3. Rangkuman Poin Kunci & Intisari Ujian (Key Exam Takeaways)

- **Definisi NIST Cloud Computing:**
  - Model yang memungkinkan akses jaringan on-demand ke kumpulan sumber daya bersama yang dapat dikonfigurasi dan dirilis dengan cepat melalui upaya manajemen minimal.
- **Tiga Model Layanan (SPI Framework):**
  - **IaaS (Infrastructure as a Service):** Menyediakan infrastruktur dasar (server, storage, networking). Konsumen mengelola OS, middleware, runtime aplikasi, dan data. Contoh: Huawei ECS, AWS EC2.
  - **PaaS (Platform as a Service):** Menyediakan platform pengembangan dan runtime terkelola. Konsumen fokus menulis kode aplikasi dan mengelola data bisnis. Contoh: Huawei CCE, App Engine.
  - **SaaS (Software as a Service):** Menyediakan aplikasi siap pakai melalui web browser. Vendor mengelola seluruh stack dari hardware hingga aplikasi. Contoh: WeLink, Office 365.
